## Game data from the OSRS Wiki
`src/main/resources/com/ultimatebank/feature/storagesavings/storage-sets.json` lists, for each player-owned house
costume room storage, which item sets it holds, their pieces, and (treasure chest) each reward's clue tier. The tier
capacities in `PohStorage` come from the same pages. It was generated by `tools/convert_wiki_storage_sets.py` from:

- [Fancy dress box space](https://oldschool.runescape.wiki/w/Fancy_dress_box_space)
- [Armour case space](https://oldschool.runescape.wiki/w/Armour_case_space)
- [Magic wardrobe space](https://oldschool.runescape.wiki/w/Magic_wardrobe_space)
- [Cape rack space](https://oldschool.runescape.wiki/w/Cape_rack_space)
- [Treasure chest space](https://oldschool.runescape.wiki/w/Treasure_chest_space)
- [Cape of Accomplishment](https://oldschool.runescape.wiki/w/Cape_of_Accomplishment) (which capes count)

Only facts about the game are taken (item and set names, set membership, clue tiers, capacities), not the wiki's
text. The wiki's content is licensed under [CC BY-NC-SA 3.0](https://creativecommons.org/licenses/by-nc-sa/3.0/);
thanks to the [Old School RuneScape Wiki](https://oldschool.runescape.wiki) and its contributors.
