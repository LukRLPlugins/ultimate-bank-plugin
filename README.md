# Ultimate Bank

An all-in-one bank toolkit for [RuneLite](https://runelite.net): tag layouts, inventory setups,
bank value, better search, and hints about which POH storage upgrades would free up bank space.
Each feature can be toggled on its own in the plugin config.

> Work in progress. See [docs/roadmap.md](docs/roadmap.md) for feature status.

## Development
Requires JDK 11.

```sh
./gradlew build   # compile + tests
./gradlew run     # launch RuneLite with the plugin loaded
```

To log in to the dev client with a Jagex account, see
[Using Jagex Accounts](https://github.com/runelite/runelite/wiki/Using-Jagex-Accounts).
